# 에셋 이름과 폴더

에디터에서 만드는 에셋은 모두 이 규칙을 따른다. `ue-editor`가 에셋을 만들 때와, 메인이 카드의 "에디터 작업"에 에셋 이름을 적을 때 쓴다.

## 폴더

- 기능 에셋: `/Game/<기능>/` (예: `/Game/Dash/`). 폴더 이름은 영어 PascalCase이고 기획서와 카드의 기능 이름에 맞춘다(`dash` → `Dash`).
- 한 기능 폴더의 에셋이 15개쯤 넘으면 종류별 하위 폴더를 만든다: `Input/`, `Materials/`, `Meshes/`, `Textures/`, `FX/`, `Audio/`, `UI/`, `Data/`.
- 플레이어 캐릭터와 그 입력: `/Game/Player/`
- 여러 기능이 같이 쓰는 것: `/Game/Shared/<종류>/`
- 맵: `/Game/Maps/`. 테스트 맵과 테스트용 에셋은 `/Game/Tests/<기능>/`.
- Fab이나 외부에서 받은 에셋은 받은 폴더 그대로 두고 옮기거나 이름을 바꾸지 않는다. 쓸 때는 기능 폴더에 우리 이름으로 머티리얼 인스턴스나 블루프린트를 만들어 감싼다.

## 이름

- 형식: `<접두사>_<이름>_<설명>_<변형>` (에픽 권장). 설명과 변형은 필요할 때만 붙인다. 예: `T_Crate_Normal`, `SM_Crate_02`, `BP_PlayerCharacter`.
- 영어 PascalCase. 띄어쓰기, 한글, 특수문자를 쓰지 않는다. Git, 명령줄, 툴셋에서 문제가 생기지 않게 하기 위해서다.
- 아래 표에 없는 종류는 같은 방식으로 짧은 접두사를 정해서 쓰고, 이 표에 한 줄 더하도록 메인에게 보고한다.

## 접두사

에픽 문서("Recommended Asset Naming Conventions")를 기본으로 하고, 문서에 없는 종류는 UE 5.8 템플릿 프로젝트의 이름을 따른다.

| 종류 | 접두사 | 출처 |
|---|---|---|
| 블루프린트 | `BP_` | 에픽 문서 |
| 블루프린트 인터페이스 | `BI_` | 에픽 문서 (템플릿은 `BPI_`) |
| 액터 컴포넌트 블루프린트 | `AC_` | 에픽 문서 |
| 애니메이션 블루프린트 | `ABP_` | 에픽 문서 |
| 위젯 블루프린트 | `WBP_` | 에픽 문서 (템플릿은 `UI_`) |
| 데이터 테이블, 커브 테이블 | `DT_`, `CT_` | 에픽 문서 |
| 열거형, 구조체 (블루프린트) | `E_`, `F_` | 에픽 문서 |
| 데이터 에셋 | `DA_` | 이 스튜디오 |
| 입력 액션, 입력 매핑 컨텍스트 | `IA_`, `IMC_` | UE 5.8 템플릿 |
| 레벨 | `Lvl_` | UE 5.8 템플릿 |
| 테스트 맵 (Functional Test) | `FTEST_` | 이 스튜디오 |
| 스태틱 메시, 스켈레탈 메시 | `SM_`, `SK_` | 에픽 문서 |
| 머티리얼, 머티리얼 인스턴스 | `M_`, `MI_` | 에픽 문서 |
| 텍스처 | `T_` | 에픽 문서 |
| 나이아가라 시스템, 이미터 | `NS_`, `NE_` | 템플릿과 에픽 `unreal-mcp` 스킬 (에픽 문서는 `FXS_`, `FXE_`) |
| 애니메이션 시퀀스, 몽타주, 블렌드 스페이스 | `AS_`, `AM_`, `BS_` | 에픽 문서 |
| 스켈레톤, 물리 에셋, 물리 머티리얼 | `SKEL_`, `PHYS_`, `PM_` | 에픽 문서 |
| 사운드 웨이브, 메타사운드 소스 | `SW_`, `MSS_` | 이 스튜디오 |
| 레벨 시퀀스 | `LS_` | 에픽 문서 |
